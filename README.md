# Sembilan — Navigasi Malaysia

A free, browser-based navigation app for Malaysia. No download, no account, no tracking.

- Turn-by-turn voice guidance in Bahasa Malaysia or English, with automatic rerouting
- Petrol stations, R&R, toll plazas and speed cameras along the route
- Motorcycle mode: rain forecast along the route with best departure time, rain radar, shelter spots, no-motorcycle road warnings, family WhatsApp alerts

Data: map tiles © Esri / © OpenStreetMap contributors · routing: OSRM · search: Photon · POIs: OpenStreetMap via Overpass · rain: Open-Meteo, RainViewer.

Prototype — routes and alerts are estimates. Always follow road signs and ride safely.
